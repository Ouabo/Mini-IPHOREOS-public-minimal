# Extended-system explanatory video (Milestone 1)

**Video:** [EXT1_Explanation_EN.mp4](EXT1_Explanation_EN.mp4)

Duration: 2 minutes 30 seconds. Resolution: 1280 x 720 at 12 frames per second. English on-screen explanations; no voice-over or audio.

## What the video shows

- 00:00-00:12: what the Extended system adds over the Baseline system (joint distance/speed belief, inferred context) and what this release (Milestone 1) fixes.
- 00:12-00:52: a fair comparison for the Baseline system. The original Baseline controller only ever offers a 0.12s pulse; `v1_fair` keeps the Baseline system's exact rule-based logic but can also use 0.24s, like the Extended system's policies.
- 00:52-01:32: the new two-step receding-horizon planner, shown on `adaptive_no_information` (context inference on, information-seeking off) -- historically the combination most at risk of preferring MEASURE indefinitely.
- 01:32-02:14: an open, unconfirmed pattern. Under an unknown +5 cm sensor bias, the information-seeking policy (`ext1`) is compared against its no-information counterpart side by side.
- 02:14-02:30: status -- what Milestone 1 addressed and what remains open.

The robot aims to stop 25 cm from the wall; the acceptable band is 21-29 cm. Gold shows simulator ground truth. Teal shows the controller's belief and its uncertainty band. The controller never receives the true distance.

## Evidence and interpretation

Every trace shown is read directly from `results_ext1/` (seed 10000, generated by `experiments/run_simulation.py`), not re-simulated or adjusted for the video. The full equations behind every panel are derived in `Mathematical_Model_EXT1.pdf`.

The "fair comparison" chapter uses the same seed and starting distance for both panels; side-by-side playback is normalised to each trial's own duration, so it is not a frame-accurate race. The "planner" chapter's worked numbers (the exact state where the no-progress cost changes the plan) are reproduced in `Mathematical_Model_EXT1.pdf`, Section 8.1, from this same trace.

The bias-scenario chapter is explicitly **not** a confirmatory result: both policies see the same development seed, not a held-out evaluation. It shows a real, reproducible pattern (information-seeking doing worse under this particular bias) worth investigating further, not a proven causal claim about information-seeking in general.

No physical robot data or hardware validation is presented. The Extended system is a desktop cognitive-architecture prototype, not a complete active-inference implementation.

## Files and reproducibility

`manifest_EN.json` records the source file hashes (`cognitive/controller.py`, `cognitive/model.py`, `cognitive/baselines.py`) and which trace file backs each panel. `preview_EN_5s.png`, `preview_EN_20s.png`, `preview_EN_80s.png`, `preview_EN_110s.png` and `preview_EN_134s.png` are still previews, one per chapter.

To rebuild, from the `Mini_IPHOREOS_EXT1` directory: `python tools/make_ext1_video.py`. Requires Pillow and imageio-ffmpeg (see `requirements.txt`) and a populated `results_ext1/` (run `experiments/run_simulation.py` first if missing).
